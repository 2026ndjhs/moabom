# 모아봄 접속 화면

이 저장소에는 Google Apps Script 앱을 여는 공개 접속 화면만 넣습니다. 명단, 제출 파일, 비밀번호, 세션 토큰, Apps Script Code.gs 및 백업은 넣지 않습니다.

게시: Settings → Pages → Deploy from a branch → main → /(root) → Save. HTTPS를 사용합니다.
예상 주소: https://2026ndjhs.github.io/moabom/

먼저 별도로 받은 Apps Script 70버전 Code.gs를 기존 Google 프로젝트에 저장하고 기존 웹 앱 배포를 새 버전으로 업데이트합니다. 새 프로젝트/초기 설정은 실행하지 않습니다.

이 화면은 로그인 폼이나 개인정보를 수집하지 않습니다. 로그인·조회·업로드·다운로드는 Google iframe 내부에서 수행합니다. 창 사이에는 공개 연결 확인 메시지만 전달합니다. 저장 위치와 서버 한도는 기존과 같습니다.

브라우저의 삽입/저장소 제한으로 실패하면 기존 앱에서 열기를 사용합니다. Google 안내 띠 숨김과 실제 학교 계정 로그인/다운로드는 게시 후 실제 환경에서 확인해야 합니다. 단순 로컬 검사로 정상 운영을 보장하지 않습니다.
