# 모아봄

접속: https://2026ndjhs.github.io/moabom/

GitHub 주소 안에서 기존 Google Apps Script 앱을 직접 표시합니다. 별도의 시작 버튼이나 Google 주소로 이동하는 버튼은 없습니다. 기존70버전과71버전 연결 요청을 함께 지원합니다.

로그인, 세션, 명단, 파일 처리는 Google 프레임 안에서 이루어집니다. GitHub에는 접속용 정적 파일만 게시하며 Code.gs, 명단, 비밀번호, 백업을 올리지 않습니다.

외부 호스트 확인을 사용하는 앱 버전은 기존 origin/source/nonce 확인 절차를 유지합니다. 개인 계정으로 로그인하거나 실제 자료를 제출하는 검사는 별도로 필요합니다.
